# TradingMachine v0.1 需求（功能明细）

> 本文件是 v0.1 功能需求的**唯一权威版本**，随仓库分发（走 PR 修改）。

## 1. 产品目标

记录交易与决策过程、执行自定义交易规则、用数据检验投资能力，
最终把自己训练成"交易机器"。

## 2. 需求变更流程

GitHub Issue 讨论 → 本文件更新（走 PR）→ 需求↔代码对照表登记（见仓库根 CLAUDE.md）。

## 3. v0.1 功能范围（P0）

### 3.1 记一笔交易
- 字段：日期时间、市场（A股/港股/美股）、代码、方向（买/卖）、价格、数量、费用（可选）、理由（必填，一句话）、情绪标签（冲动/计划内/犹豫）、截图附件（可选）
- 验收：30 秒内完成一笔录入；支持人民币/港币/美元

### 3.2 规则检查（首版内置硬编码）
- 单只股票首次买入 ≤ ¥30,000（超出 → 警告并要求写明理由）
- 单只股票仓位 ≤ 30%（按成本计，超出 → 警告）
- 验收：触发规则时强提醒并记录"违规标记"，不阻断录入

### 3.3 交易日志
- 每只股票一条时间线：买入理由 → 加仓/减仓及理由 → 卖出理由
- 验收：能按股票回看完整决策链

### 3.4 持仓概览
- 由交易流水自动推导当前持仓与盈亏（含汇率折算）
- 验收：与券商 App 数字误差 < 1%（费用口径内）

## 4. 数据录入策略

- 成交当场手动录入（约 30 秒/笔）——心路历程必须在决策时刻记录，晚间回忆会美化
- 持仓由交易流水推导，不做持仓快照录入
- 截图仅作证据附件，不做 OCR 数据源
- 历史数据：v0.3 交割单导入后补，不阻塞 v0.1
- 券商 API：A股个人账户无合规好用的 API，短期不依赖

## 6. 非功能需求

- 数据本地存储优先（持仓金额敏感，不上传第三方）
- 单机可用，无账号体系

## 7. 明确不做（v0.1）
